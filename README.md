# MindMantra 🌿

**MindMantra** is a **college final year project** and an AI-powered mental health assistant that predicts mental health conditions based on symptoms and provides personalized follow-up questions and guidance. The system combines machine learning models with an interactive chatbot for smarter support.

## 🔹 Features
- Symptom-based **mental health condition prediction**  
- Dynamic **follow-up questions** for refined diagnosis  
- **Random Forest ML model** for accurate prediction  
- **Interactive chatbot** for emotional support  
- Condition-specific **precautions and guidance**  

## 💻 Technologies Used
- Python  
- Scikit-learn  
- Pandas & NumPy  
- Streamlit for web app  
- Natural Language Processing for chatbot
